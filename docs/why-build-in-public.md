# Why build in public

Building in the open means the work is visible while it happens, not only
after it is finished.

## What it buys us

1. **Trust.** Anyone can inspect the history and see how decisions were made.
2. **Momentum.** Small public commits add up; the graph itself is motivation.
3. **Feedback.** People can react to real progress instead of promises.
4. **Compounding.** Every public artifact can be discovered and reused.

## The rule

If a change *can* be public, it *is* public. Private work is the
exception, used only when it must be.
