# Commit conventions

Messages follow `type: subject`.

| Type     | Meaning                                  |
| -------- | ---------------------------------------- |
| `docs:`  | documentation only                       |
| `site:`  | changes under `site/`                    |
| `script:`| changes under `scripts/`                 |
| `buildlog:` | a new open-build log entry            |
| `chore:` | repo housekeeping                        |
| `feat:`  | a new capability                         |
| `fix:`   | correcting something that was broken     |

## Subject rules

- Imperative mood: "add", not "added".
- Lowercase subject after the prefix.
- One commit, one concern.
