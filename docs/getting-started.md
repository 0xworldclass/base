# Getting started

`base` is a public workspace. Everything here is built out in the open.

## Clone and look around

```sh
git clone https://github.com/0xworldclass/base.git
cd base
```

## Structure

- `docs/` — the guides you are reading now
- `site/` — a small static landing page
- `scripts/` — small utilities
- `buildlog/` — the running open-build log

## Run the site locally

```sh
./scripts/serve.sh
```

Then open the printed URL. No build step, no dependencies.
