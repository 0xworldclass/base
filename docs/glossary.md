# Glossary

| Term          | Meaning                                              |
| ------------- | ---------------------------------------------------- |
| Open build    | Doing the work in public commits, as it happens      |
| Build log     | The numbered entries in `buildlog/`                  |
| Cadence       | The steady rhythm of public commits                  |
| Proof of work | The commit history itself                            |
| Public commit | A commit visible on a public repository              |
| Shelf         | A set of related changes prepared for a commit      |
