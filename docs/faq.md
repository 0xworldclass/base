# FAQ

**Why are there so many small commits?**
Because consistent public steps are the point. The history is the artifact.

**Can I reuse this structure?**
Yes — everything is MIT licensed. Copy it, adapt it, build in the open.

**Why plain HTML instead of a framework?**
The site is a landing page. Plain HTML loads instantly and never breaks
on a framework upgrade.

**Do private commits count?**
No. Only public commits are tracked here; private work cannot be counted
because it cannot be seen.
