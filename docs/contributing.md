# Contributing

This project is built in the open and welcomes public contributions.

## How

1. Fork the repository.
2. Make your change in a short-lived branch.
3. Keep commits small and well-described.
4. Open a pull request against `main`.

## Style

- One concern per commit.
- Update docs when you change behavior.
- Add a build-log entry for notable changes.

## Ground rules

Be kind, be concrete, and show the work.
