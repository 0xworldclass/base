# Tooling

The toolchain is intentionally boring.

| Tool       | Used for                        |
| ---------- | ------------------------------- |
| git        | history, the core of everything |
| bash       | glue scripts in `scripts/`      |
| python3    | generators and checks           |
| plain HTML | the site, no framework needed   |

## Rules for adding tools

- Prefer tools that are already installed.
- Prefer tools with zero configuration.
- Every new tool must earn its place in this doc.
