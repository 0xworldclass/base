# Decision record

A running list of the calls that shaped this repo.

| # | Decision                          | Why                                            |
| - | --------------------------------- | ---------------------------------------------- |
| 1 | Public by default                 | Visibility is the point of this project        |
| 2 | Plain HTML site, no framework     | Small, fast, zero maintenance                  |
| 3 | Append-only numbered build log    | Honest, gap-visible record of progress         |
| 4 | One concern per commit            | History stays readable and revertable          |
| 5 | Boring tooling only               | Attention goes to the work, not the tools      |
