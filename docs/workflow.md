# Workflow

The loop is deliberately small:

1. Pick the next smallest useful thing.
2. Do it.
3. Commit it with a message that explains the why.
4. Push it to the public repo.
5. Write a short build-log entry if it mattered.

## Branching

- `main` holds the current state of the open build.
- Feature branches are short-lived and merged quickly.

## Cadence

Consistency beats intensity: steady commits on many days beat a single
burst followed by silence.
