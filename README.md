# base

> **Building in the open, consistently.** 100+ public commits and counting.

`base` is a public, open-build workspace. Every change happens in public commits,
so the history itself is the proof of work: ideas, docs, scripts, and site assets
shipped incrementally, out in the open.

## What lives here

| Path        | What it is                                             |
| ----------- | ------------------------------------------------------ |
| `docs/`     | Guides and notes on how this project builds in public  |
| `site/`     | A small static landing page for the open build         |
| `scripts/`  | Utility scripts used around the repo                   |
| `buildlog/` | A running log of open-build entries                    |

## Principles

1. **Public by default** — if it can be public, it is public.
2. **Small, steady steps** — many small commits over few giant ones.
3. **Show the work** — the history is the documentation.

## Status

- ✅ Public repository
- ✅ 100+ public commits — building in the open consistently
- ℹ️ Only public commits are tracked; private repo commits cannot be counted

Run `./scripts/stats.sh` for live numbers.
